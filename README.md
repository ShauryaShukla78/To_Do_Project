# Python Todo Application

A feature-rich Todo Application built using Python.  
Initially developed as a CLI-based project and later upgraded to a GUI application using Tkinter.

## Features

- Add Tasks
- View Tasks
- Edit Tasks
- Delete Tasks
- Complete Tasks
- Search Tasks
- Filter Tasks
- Sort Tasks
- Persistent File Storage using `.txt`

## Technologies Used

- Python
- Tkinter
- File Handling
- OOP Concepts

## Project Structure

```bash
todo-app/
│
├── backend.py
├── gui.py
├── tasks.txt
├── completed.txt
└── README.md
```
